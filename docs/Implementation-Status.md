## الفجوات المستمرة

- **F01 الإضافات:** سجل بيانات بمصادر وتراخيص وصلاحيات وتوافق واعتماديات ومراجعات وقرارات متحققة؛ تبقى حزم الكود وتوقيع الناشر والاختبار المعزول والتثبيت والتفعيل والتراجع التنفيذي غير منفذة.
- **F03 مكتمل:** المحولات والقاموس والمخطط والإصدارات والأصل والتوقيت والجودة موثقة ومختبرة. التوافق الكامل معOCSFوجمعEVTXأو سجلات حية توسعات مستقلة خارج عقدF03المعتمد.
- **F05 التحديثات:** توقيعEd25519ومفاتيح ثقة مثبتة ومنع خفض التسلسل متاحة اختياريًا؛ لاTUFأو إدارة تلقائية لدوران المفاتيح أو تحديث آلي. الحزم المرفوعة غير موقعة بمفتاح مالك افتراضي، وجلب معلومات عن ثغرة لا يثبت إصلاحها.
- **E05 الصيانة:** فحص محدود وإصلاح صلاحيات مثبتة وطلبات متابعة؛ لا ترقية لجميع أدوات النظام أو إصلاح مستقل لكل الأعطال. جدولان إضافيان يُنشآن دون تحويل الأدلة أو حذف البيانات.
