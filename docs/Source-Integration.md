# دمج الملف الكامل — الإصدار 0.3.0

حُفظ ملف `Cyber-Platform-Requirements.md` كاملًا في `docs/Requirements-Source.md` دون تعديل. يضم173726 بايت و876 سطرًا. لا تحذف الفهرسة النصوص أو الجداول أو التعليمات التاريخية، ولا تعيد صياغتها على أنها وظائف منفذة.

أضيف فهرس ضمن حزمة التطبيق نفسها، في `cyber_platform/requirements.json`؛ لا يعتمد الاطلاع على وجود مجلد docs بجوار التطبيق المثبت. يحتوي على:

- 411 مقطعًا تغطي الملف من أوله إلى آخره بالترتيب، مع العناوين وأرقام الأسطر. جمع نصوصها يعيد الأصل مطابقًا بالبايت وبصمة SHA-256.
- 61 سجلًا: المتطلبات الأساسية19، ومجموعات F/E/N/Q وعددها22، والأقسام الأصلية20. لكل سجل مرجع إلى نصه وتقييم نطاق التنفيذ ومراجع كود أو توثيق. تبقى التفاصيل الأخرى كلها قابلة للبحث في المقاطع، ولا يدعي العدد61 أنه عدد جميع القدرات الذرية في الرؤية.
- 35 رابط مصدر كما وردت في الملف؛ لا يعني وجودها جلبها اليوم أو سلامة كل ادعاء تقني أو تثبيت أدواتها.
- 28 اسم ملف أو صورة أو أرشيف ورد ذكره. ورود الاسم لا يعني إرفاق محتواه أو استعادة الإصدار التاريخي؛ إذا وجد الاسم نفسه حاليًا فهذا تطابق اسم فقط.
- تعديلات المالك الأحدث: إزالة هيكل المختبرات، وإضافة الحماية والتعلم الأخلاقي، والملكية الخاصة، وحد35GB الوارد في آخر تعديل تاريخي بدل20GB، مع تمييز الهدف عن قياس صورة فعلية.

تظهر المعلومات في صفحة **ملف المشروع ومتطلباته** بعد المصادقة. يمكن تصفية المتطلبات بالحالة، أو البحث في كامل نص الملف، أو عرض النص الأصلي لكل بند. تنزيل الأصل والتصدير وإضافة مرجع إلى مشروع كلها محمية بحساب المالك؛ الإضافة إلى المشروع تتطلب CSRF ولا تقبل مسارًا بديلًا من العميل. تحفظ نسخة الملف كمرجع بيانات، ولا تنفذ أي أوامر واردة فيه ولا تمنح النموذج صلاحيات منه.

تحديث الفهرس بعد مراجعة الملف أو تقييمات النطاق:

```bash
python3 scripts/build_requirements.py
python3 scripts/build_requirements.py --check
```

الأمر الثاني يتحقق دون كتابة الملفات. اختبارات التغطية تطابق كل بايت وكل نطاق أسطر، وتتحقق من وجود النص المرجعي ومراجع التنفيذ لكل سجل، ومن البحث والترقيم والتصدير والاستيراد وعدم التكرار والمصادقة. لا يصدر الفهرس نسبة اكتمال كلية.
