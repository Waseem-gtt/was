# E02 — هوية ومساحة عمل لكل قسم ومنصة: وظائف منفذة ومختبرة

تحديث0.20: الوظائف المذكورة منفذة ومختبرة، لكن الدفعة والقسم المرتبط غير مكتملين وفق [توجيه المالك النافذ](Completion-Policy-0.20.md). المرجع الحالي [كشف التسليم](Delivery-Status-0.20.md).

أكمل إصدار0.17البندE02كما صيغ في ملف المالك: هوية ومساحة عمل لكل قسم رئيسي ومنصة فرعية، باستخدام محرك وخدمات مشتركة ومعرفات ثابتة. يشمل التنفيذ22قسمًا و109منصات، أي131مساحة؛ ليست131خدمة مستقلة أو131نموذجAI.

## معيار القبول وما أُنجز

| جزء المتطلب | التنفيذ |
|---|---|
| المعرف الثابت | معرف القسم ومعرف المنصة الأصليان؛ تغيير الاسم أو اللون لا يغير المعرف أو ربط الأدوات |
| عنوان ووصف وأيقونة وألوان | إعدادات مالك محفوظة، مع قائمة أيقونات وألوان محددة تمنع حقنCSSأو مورد خارجي |
| صفحة مستقلة ومسار رجوع | رابط `#workspace-ID` قابل لإعادة الفتح؛ رجوع للقسم الأب والمنصة الأم |
| أدوات وتقنيات المساحة | أدوات مرتبطة فعلية بدليلها ومحددات مدخلها؛ الموضوعات والمراجع ظاهرة منفصلة عن جاهزية التنفيذ |
| خريطة وجدول مكافئ | قسم إلى منصاته، أو منصة إلى أدواتها، بأسهم وعلاقة موضحة وروابط تشغيل وجدول بديل |
| إعدادات ومساحة عمل خاصة | تبويبات نظرة وأدوات وخريطة وهوية؛ حفظ صفحة البداية المطلوبة وإعادة تحميلها |

اختُبرت الهويات الـ131من الواجهة، واختُبر تخصيصها جميعًا من الخلفية مع ثبات المعرفات والأدوات. فحص المتصفح الحفظ وإعادة التحميل وصفحة البداية واللون والوصف والأيقونة والانتقال من خريطة القسم إلى المنصة ثم دليل الأداة. يفصل [تقرير التحقق](Validation-0.17.md) النتائج النهائية.

## الاستخدام

افتح «الأقسام والتخصصات»، واختر قسمًا، ثم «فتح مساحة عمل القسم». المنصات أسفل القسم لها زر «مساحة عمل المنصة». يمكن الوصول أيضًا من الخريطة الافتتاحية أو صفحة «مساحة العمل» في القائمة.

داخل المساحة اختر «إعدادات الهوية»، وعدل عنوانها ووصفها وأيقونتها ولونها وصفحة البداية، ثم احفظ. يظهر التعديل في التنقل والخريطة بعد تحديث البيانات. النطاق131هوية معروفة، ولا يسمح الطلب بتغيير معرف أو أب أو أداة أو صلاحية. عند تعارض المراجعات يحتفظ النموذج بتعديلاتك حتى تختار إعادة تحميل النسخة الحالية.

الإعدادات تخص تثبيت المالك كله، وسياق المشروع المختار مشترك بين المساحات. لا تمثل الألوان أو اختلاف الصفحات حد عزل أو حسابات مستخدمين متعددة. المنصة التي لم تُربط بها أداة تُعرض بهذا الوصف صراحة؛ إكمال الهوية لا يمنحها أدوات غير منفذة. تشغيل نموذج محلي أو تجهيزVirtualBoxأو جميع تقنيات الأقسام بنود أخرى تبقى منفصلة.

## الحفظ والتدقيق

تُحفظ الهوية في سجل إعدادات بمعرف ثابت ورقم مراجعة، ويربط حدث التدقيق بصمة محتواها. عند القراءة يجب أن تطابق آخر حدث تحديث لتلك الهوية؛ لا تقبل إعادة سجل قديم أو حذفه من قاعدة البيانات لإعادة الهوية إلى الصفر بصمت. فشل التدقيق أو التحقق من هوية التخزين يتراجع عن الحفظ. حدود العنوان120حرفًا والوصف2000حرف؛ لا تُفسر النصوص شيفرةHTMLأو أوامر.

واجهات المالك: `GET /api/workspaces?id=ID` و`POST /api/workspaces/settings`. الحفظ يقبل فقط `id,revision,title,description,icon,color,landing` مع المصادقة وCSRF. لا تعطي هذه الإعدادات صلاحيات تنفيذ إضافية للأداة أو المساعد.
