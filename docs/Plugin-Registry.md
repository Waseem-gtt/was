# سجل مراجعة الإضافات — 0.12

أضاف0.20[مسارًا منفصلًا لحزمWasmتنفيذية موقعة](Plugin-Installations.md). يبقى هذا السجل مراجعة بيانات فقط، ولا يمنح اعتماده إذن تشغيل. قسم الإدارة والدفعة ما زالا غير مكتملين.

صفحة **إدارة الإضافات** تحفظ بيانات الإضافات وقرارات مراجعتها داخل المشروع الخاص. يرفع المالك بيانJSONكأصل، ثم يسجله وتُحفظ بصمته ومصدره وترخيصه وصلاحياته واعتمادياته وتوافقه. لا تُنزّل الصفحة شيفرة من رابط المصدر، ولا تثبت إضافة أو تشغلها. حالة`approved`تعني اعتماد بيانات البيان فقط، وليست توقيع ناشر أو إثبات اختبار كود أو تفعيلًا داخل البرنامج.

مثال بيان اصطناعي:

```json
{
  "id": "owner.example",
  "version": "1.0.0",
  "license": "MIT",
  "source": "https://example.test/plugin",
  "permissions": ["selected_evidence.read"],
  "dependencies": [],
  "compatibility": {
    "python_min": "3.11",
    "python_max": "3.13",
    "platform": "linux"
  }
}
```

الحقول الخمسة الأولى مطلوبة، و`dependencies/compatibility`اختيارية. تُرفض الحقول الإضافية. المصدر رابطHTTPSدون بيانات دخول أو استعلام أو جزء لاحق. التوافق المعلن يصفLinuxوحدي إصدارPythonالأدنى والأعلى؛ لا ينفذ البرنامج فحصًا فعليًا لحزمة الإضافة أو متطلباتها الأصلية. معرف الترخيص تصريح يحتاج مراجعة مستقلة للحقوق، ولا يتحقق البرنامج من صدق رابط المصدر أو من ملكيته.

تبدأ الإضافة بحالة`pending`. القرارات`approve/disable/revoke`تتطلب سببًا محفوظًا، وتُضاف كمراجعات ثابتة مرتبطة بالسجل السابق. لا يتكرر انتقال إلى الحالة نفسها. سحب مراجعة يمنع إعادة اعتمادها؛ يمكن تسجيل إصدار أعلى يمر بالمراجعة من جديد. لا يستبدل التسجيل أصلًا أو إصدارًا محفوظًا.

يفحص العرض الصلاحيات ومعرف الترخيص والتوافق والاعتماديات، ويصدر رسمًا بعقد وروابط وملاحظات. تمنع الصلاحيات خارج قائمة مراجعة البيانات، أو اعتمادية مفقودة أو غير معتمدة أو بإصدار مختلف، أو دورة اعتماديات، قرار الاعتماد. قائمة المراجعة الحالية هي`selected_evidence.read/derived_evidence.write/settings.read`؛ هذه أسماء بيانات للمراجعة ولا تمنح أي صلاحية تنفيذ. تطابق إصدار الاعتمادية رقمي دقيق، وليس محلل قيودpipأو حل اعتماديات عام.

إذا تعطلت اعتمادية أو تغير توافق البيئة، يبقى قرار المالك التاريخي`state:approved`محفوظًا، وتظهر الحالة الفعلية`effective_state:blocked`مع السبب. تنتقل ملاحظات الاعتماديات المانعة إلى الإضافات التابعة. لا يصح تفسير اعتماد قديم على أنه صلاحية حالية دون قراءة الملاحظات.

تتحقق قراءة السجل من الأصل وبصمته وتسلسل المراجعات وروابط الأدلة وواقعة الإنشاء في التدقيق وتطابق الفهرس مع الأدلة المحفوظة. يضاف دليل`plugin-registry`والفهرس والتدقيق بصورة ذرية. عند فشل النشر لا يفترض أن القرار حُفظ. لا تمنح السلسلة ثقة ناشر خارجية أو حماية مطلقة أمام مدير يعيد كتابة قاعدة البيانات والتدقيق معًا.

الحدود:20إضافة لكل مشروع، و20مراجعة لكل معرف، و16KiBللبيان، و10اعتماديات و20صلاحية لكل بيان، و8MiBلقراءة الإثبات في العرض. لا تُحذف المراجعات تلقائيًا. يمكن تصدير سجلJSON؛ بيانات المالك وقراراته تبقى خارجGitوتشملها النسخ الاحتياطية المشفرة.

هذا السجل وحده خطوة جزئية فيF01. أضيف في0.20مسار مستقل لحزمWasmموقعة واختبارات معزولة وتثبيت وتفعيل واستعادة فعلية، ويبقى قسم الإدارة غير مكتمل. راجع[حالة التنفيذ](Implementation-Status.md) و[API](API.md) و[تقرير التحقق](Validation-0.12.md).
