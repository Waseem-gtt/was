# مراجعة اكتمال F03 وF04 — 2026-10-23

تحديث0.20: الوظائف المذكورة منفذة ومختبرة، لكن الدفعة والقسم المرتبط غير مكتملين وفق [توجيه المالك النافذ](Completion-Policy-0.20.md). المرجع الحالي [كشف التسليم](Delivery-Status-0.20.md).

«مكتمل» يعني تنفيذ جميع شروط البند الأصلي بعد تعديلات المالك والتحقق من عملها. وجود شرط ناقص يبقي البند جزئيًا. لا تختزل الوظيفة إلى جزء ثم تسمّي البند كله مكتملًا.

هذه مراجعة لتنفيذ0.18 الموجود؛ ليست إضافة وظائف جديدة أو إعلان اكتمال المنظومة. أزيلت عبارة «مكتمل ضمن نطاقه» من تسمية الحالة في قائمة المتطلبات.

## F03: لغة مشتركة للأحداث الأمنية

المصدر: [ملف المتطلبات](Requirements-Source.md)، السطر65، والتفصيل في فقرة القسم03. الشروط: محولات وقاموس ونسخ مخطط، حفظ الأصل والتوقيت والجودة.

| الشرط الأصلي | التنفيذ ودليل التحقق |
|---|---|
| محولات ولغة مشتركة | Windows JSON وWindows XML وRFC5424 وCSV تنتج was.event/1؛ اختبارات test_event_adapters وtest_windows_xml وtest_event_schema تنفذ التحويل الحقيقي في العامل |
| قاموس | أسماء الحقول وأنواعها ومعانيها وقواعد كل محول في event_schema.describe، مع عرض وتنزيل من الواجهة |
| نسخ مخطط | schema_version وبصمة قاموس وJSON Schema منشور؛ اختبارات رفض النسخة المجهولة وتغير القاموس والتلاعب بالمخطط |
| حفظ الأصل | ملف أصلي ببايتاته وبصمته وعلاقة أصل–مشتق؛ اختبارات الحفظ وإعادة التشغيل ورفض تغيير الأصل في test_event_ingest وtest_event_schema |
| التوقيت | النص والإزاحة والدقة الكسرية والترتيب والتكرار محفوظة؛ اختبارات Windows ذي7منازل وغياب التوقيت والإزاحة غير المعلومة |
| الجودة ومراجعة التحويل | تعداد الحقول المجهولة وفجوات كل سجل والتحقق من اتساقها؛ رفض جودة مزورة أو فشل سجل بدل حفظ نتيجة ناقصة |

## F04: مكتبة قواعد كشف قابلة للاختبار

المصدر: السطر66 والتفصيل في فقرة القسم03. الشروط: مصدر وترخيص ونسخة وfixtures وتغطية وإعادة اختبار.

| الشرط الأصلي | التنفيذ ودليل التحقق |
|---|---|
| المصدر والترخيص | بيانات مطلوبة للقواعد المدمجة وقواعد المالك، محفوظة ضمن النسخة؛ اختبارات مكتبة detection وقواعد المالك |
| النسخة ومراجعتها | معرف ثابت ونسخ ومراجعات وبصمات؛ رفض الرجوع إلى فهرس قديم، وتقادم عينة الإصدار السابق |
| عينات مرجعية | أمثلة موجبة وسالبة للمدمج، وتسجيل ملف مالك أصلي مع فهارس النتائج المتوقعة؛ اختبارات التسجيل والحفظ والتلاعب والحدود |
| التغطية | فحص جميع القواعد الحالية، بما فيها قاعدة بلا عينة أو بعينة متقادمة؛ لا يجتاز تقرير ناقص التغطية |
| إعادة الاختبار | إعادة تنفيذ في عامل محدود وتقرير جديد محفوظ، بقياسات TP/FP/FN/TN؛ اختبارات إعادة التشغيل والفشل والقياسات المتناقضة |
| حفظ الأصل ومراجعة إصدار القاعدة | ربط العينة ببصمة الأصل والقاعدة والمحرك وإيصال ثابت وتدقيق؛ اختبارات تغيير المصدر والإصدار والاستعادة المشفرة |

اختبارات المتصفح المسجلة في [تحقق0.18](Validation-0.18.md) تغطي العرض والرفع والتحويل وتسجيل العينة والتشغيل والتصدير ورفض الرد المتأخر. جميع الشروط أعلاه لها تنفيذ، ولا يوجد شرط معلّق في هذين البندين بحسب نص المصدر المتاح. OCSF وSigma موصوفان في المصدر بوصفهما مرجعين مرشحين. لا يحوّل اكتمال هذين البندين حالة قسم الدفاع أو البنود الأخرى من جزئية إلى مكتملة.
