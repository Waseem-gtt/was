# تقارير المشروع — 0.11

ينشئ المالك تقريرًا ثابتًا من صفحة **تقارير المشروع**، يختار فيه حتى50دليلًا، وحتى5تشغيلات خطط، ولقطة فحص تغطية مكتملة اختيارية. يبقى التقرير داخل بيانات المشروع الخاصة؛ تنزيل JSON أو HTML إجراء يدوي إلى جهاز المالك، ولا يرفع التطبيق التقرير إلى Git أو جهة خارجية.

يحتوي التقرير هوية المشروع ووقت البناء، وأسماء الأدلة وأنواعها وأحجامها وبصماتها، وملخصات كشف يعاد التحقق منها ضمن الميزانية، ونسخًا من تقارير الخطط ولقطة التغطية، وبصمة محرك التقرير وسلسلة التدقيق وقت البناء. لا ينسخ بايتات الملفات الأصلية. قد تتضمن الأسماء والنتائج المشتقة معلومات حساسة؛ راجع التقرير قبل مشاركته خارج جهازك.

حد التقرير1MiBو50تقريرًا محفوظًا لكل مشروع. لا يُحذف الأقدم بصمت. لا يمكن تضمين تقرير مشروع داخل آخر. حد كل دليل مختار4MiB؛ ميزانية32MiB مشتركة لقراءات الأدلة وإثبات الخطط، مع حساب مسبق محافظ لتكرار مدخلات العقد وإثبات القوالب. قد يرفض تقرير مشروع كبير هذه الميزانية ويحتاج تقليل الاختيارات.

تُعاد مراجعة ثلاثة تقارير كشف مختلفة كحد أقصى مع مهلة بدء3ثوانٍ بين الاستدعاءات؛ العامل الجاري له حدوده المعروفة وقراءات مكتبة ومصدر محدودة إضافية لا تُدعى ضمن القياس المباشر. البقية تحمل `not_replayed_budget` ولا تُعرض كاختبارات متحققة. يمكن أن يحتوي التقرير نتيجة فاشلة أو غير مقيّمة؛ إنشاؤه ليس إعلان نجاح تحليلي.

الحالة التفصيلية للخطط تعيد التحقق من مصادرها ونتائجها قبل تضمينها. فحص التغطية المرفق لقطة تاريخية بـ`snapshot_only`، وليس إثبات حماية حالية أو لقطة ملفات ذرية. يُحفظ التقرير كدليل `project-report` مستقل ببصمة، ورابط إلى أول دليل مختار عند وجوده؛ وتوجد جميع المراجع الأخرى داخل البيان.

زر **إعادة فحص مراجع التقرير** يتحقق من بايتات الأدلة وسجلات الخطط والتغطية المحفوظة ضمن الميزانيات، ويظهر التغير أو الفقد. لا يعيد جميع التحليلات أو يثبت صحة تسميات البيانات أو الفعالية الدفاعية. تغير المحرك أو تقدم الخطة بعد إنشاء التقرير يظهر كتغير مرجع، ويبقى التقرير القديم محفوظًا بتاريخ لقطة إنشائه.

HTML مستقل دون JavaScript أو موارد خارجية، مع ترميز النصوص وسياسة CSP. يشمل التصدير أسماء الملفات والملخصات نفسها؛ لا يُنفذ أي نص من المدخلات. لا يمثل التقرير توقيع ناشر أو اعتماد تحقيق قضائيًا. تدخل التقارير وسجلات المراجع في النسخ الاحتياطية المشفرة القائمة، ويظل تخزين التشغيل نفسه غير مشفر بواسطة التطبيق.
