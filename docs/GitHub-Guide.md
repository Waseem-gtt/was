# أين تجد المشروع في GitHub؟

المستودع المعتمد هو [Waseem-gtt/was](https://github.com/Waseem-gtt/was). سجّل الدخول بحسابك، ثم افتح صورة الحساب أعلى الصفحة واختر **Your repositories** وابحث عن **was**. يجب أن ترى بجانب اسم المستودع شارة **Private**. ملف الكود والتقارير موجودان داخل المستودع؛ لا نحتاج وضعهما في إعدادات حسابك، ولم نغيّر إعدادات الحساب.

من تبويب **Code** ستجد:

- `README.md` ثم [فهرس المشروع](Project-Index.md) للوصول لبقية الملفات.
- `docs/` للمتطلبات والتوثيق وحالة التنفيذ وتقارير الاختبار.
- `reports/validation-0.5.json` لملخص التحقق التاريخي القابل للقراءة البرمجية.
- `reports/validation-0.6.json` و`docs/Validation-0.6.md` لنتائج الإصدار0.6وفريق الوكلاء والإصلاح المتحقق.
- `releases/0.5.0/` لأرشيف المصدر وwheel وبصمات الحزمة التاريخية وبيان منشئها. هذا مجلد داخل Code، وليس إعلانًا بإنشاء إصدار GitHub Release.
- `cyber_platform/` للكود، و`tests/` للاختبارات، و`.github/workflows/ci.yml` لتعريف فحوص Actions.

لفتح ملف اضغط اسمه، ولتنزيل حزمة افتحها ثم استخدم **Download raw file**. أرشيف0.5 يمثل الالتزام المثبت في بيان المنشأ؛ التغييرات الأحدث تظهر في ملفات المستودع الحالية وسجل **Commits**.

## الخصوصية ونتائج الفحوص

يمكنك مراجعة من لديه وصول من **Settings** داخل المستودع ثم **Collaborators** أو **Collaborators and teams** بحسب واجهة GitHub. إعدادات المستودع تختلف عن **Settings** في قائمة حسابك. لا تضف متعاونين أو تنشئ Pages إذا أردت إبقاء الوصول مقتصرًا عليك. المستودع الخاص يخضع أيضًا لصلاحيات GitHub وأي مؤسسة أو تطبيقات منحتها وصولًا؛ كلمة Private وحدها لا تثبت أن قائمة المتعاونين خالية.

افتح تبويب **Actions** لرؤية آخر تشغيل، ثم اختر التشغيل المطابق للالتزام المطلوب واقرأ الوظيفة الحمراء وسجل الخطأ. علامة خضراء لإصدار قديم لا تثبت سلامة آخر التغييرات. تقرير0.5 يوضح أن سجلات GitHub البعيدة لم تُقرأ حينها بسبب سياسة الشبكة؛ نتائج الاختبارات المحلية موثقة منفصلة.

قاعدة البيانات وكلمات المرور ورمز `setup-token` والأدلة والنسخ الاحتياطية وأوزان النماذج تبقى خارج Git. ملفات الحزمة المنشورة هنا فُحصت كأرشيفات كود وتوثيق، ولا تتضمن بيانات تشغيل المالك. لا ترسل رمز الدخول أو كلمة المرور في Issue أو ملف داخل المستودع.
