# مسارات التعلم — 0.12

تعرض صفحة **مسارات التعلم** خمسة مسارات مرتبة تغطي الدروس العشرين الموجودة، بأربعة دروس لكل مسار. تحفظ كل محاولة داخل المشروع المختار، ويمكن إعادة تحميل التقدم وتنزيله بصيغةJSON. هذه تقييمات فهم لمفاهيم محددة على أمثلة اصطناعية ثابتة؛ اجتيازها ليس شهادة إتقان أو تصريحًا لاختبار هدف خارجي.

| المسار | ترتيب الدروس |
|---|---|
| أسس التعامل مع الأدلة | سلامة الأصل، المؤشرات والسياق، الويب، أحداث الدخول |
| مراجعة الأنظمة والاتصالات | التحليل الساكن، التدفقات، الهوية، الحاويات |
| البرمجيات والبروتوكولات | SBOM، حدود السجلات، جرد التشفير، البرامج الثابتة |
| الأنظمة المادية والإشارات | النموذج الحراري، الطيف، تسلسل القياسات، CAN |
| المصادر والذكاء الاصطناعي والحوكمة | CCSDS، استنتاجاتAI، الخصوصية، بيان الإضافة |

يُفتح الدرس التالي عند وجود إجابة صحيحة صالحة لكل الدروس السابقة في المسار. تبقى المحاولات الخاطئة مسجلة؛ لا يمحوها اجتياز لاحق. تُحسب حالات`passed/attempted/available/locked/stale`من المحاولات المتحققة، وتظهر أعداد المحاولات والإجابات الصحيحة. المحاولات المستقلة القديمة عبر`learning/attempt`تبقى متاحة، ولا تتحول تلقائيًا إلى تقدم في المسارات الجديدة.

تختار الخدمة الدرس والعينة والأداة من قائمة ثابتة. لا تقبل عنوان هدف أو أوامر أو محتوى تمرين من العميل. يعمل التحليل في عاملPythonجديد بحد3ثوانٍ انتظار، و3ثوانٍCPU، و384MiBذاكرة؛ لا يوجد رجوع إلى التحليل داخل خيطHTTP. هذه حدود موارد للكود الموثوق، وليست عزل ملفات أو شبكة.

يحتفظ دليل`learning-assessment`بنسخة الدرس والإجابة والنتيجة والعينة الاصطناعية وبصماتها وبصمة المنهج والمحرك. ينشر الدليل والفهرس والتدقيق بمعاملة واحدة. تتحقق قراءة التقدم من البنية والبصمات ومصدر السجل؛ لا تعيد تنفيذ التحليل في كل عرض. تغير المنهج أو المحرك يجعل المحاولة قديمة ويمنع استخدامها لفتح متطلب سابق، مع بقاء التاريخ محفوظًا. لا تعني هذه البصمات توقيعًا خارجيًا أو حماية من مدير جهاز يعيد كتابة كل السجلات.

الحدود:200محاولة لكل مشروع، و20محاولة لكل درس، و32KiBللدليل؛ ميزانية قراءة تقييمات التقدم القصوى6.25MiB. لا تُحذف محاولات قديمة تلقائيًا لتجاوز الحدود. ترتبط البيانات بالمشروع وتشملها النسخة الاحتياطية المشفرة؛ قاعدة البيانات الحية نفسها لا تُشفّر بهذه الميزة.

المسارات الجديدة توسعE03جزئيًا، ولا تغطي إتقان كل أداة أو تقنية أو تخصص في الملف الأصلي. راجع[حالة التنفيذ](Implementation-Status.md) و[API](API.md) و[تقرير التحقق](Validation-0.12.md).
