# التحقق من الإصدار 0.3.0 — 18 أكتوبر 2026

## نتائج التنفيذ

- نجح سكربت التثبيت المتكرر من جذر المستودع، مع إنشاء venv وتثبيت اعتماد التشفير وتشغيل الاختبارات.
- بُنيت حزمة wheel0.3 وثُبتت في مسار مستقل؛ تحقق خارج مجلد المصدر تحميل الكتالوج والأصول الثابتة و21 أداة و20 درسًا، وبدء HTTP وقراءة SQLite وإغلاق عامل الجدولة.
- نجح **66 اختبارًا** دون فشل أو تجاوز في `python -m unittest discover -v`. تتضمن حالة تكامل واحدة21 subtests للأدوات المسجلة؛ لا تضاف مرة أخرى إلى العدد66.
- نجحت **15 مجموعة سيناريو Chromium** دون أخطاء JavaScript: التهيئة والمصادقة، إنشاء مشروع ورفع أصل، تحليل IOC وقبول، فشل متعمد لسير عمل، خريطة وفحص دليل، جميع الأقسام22 ومنصاتها، تقييم تعلّم خاطئ وصحيح، تجربة قواعد كشف، معرفة وبحث بناقل شبكة اختباري، تنزيل نسخة مشفرة، عرض11 صفحة عند390 و320 بكسل دون تمدد أفقي، والخروج.
- أزيلت سجلات labs من الكتالوج. تحققت الاختبارات من22 قسمًا و109 منصات، وتفرّد المعرفات، وصلاحية روابط الأدوات والمراجع. لم تتغير ملفات المالك وأدلته.
- اختُبرت20 محاولة تعلّم صحيحة ومحاولة خاطئة، وحفظ المدخل الاصطناعي وبصمته ونتيجة التحليل، ورفض حقل هدف أو أمر غير مسجل، والمصادقة وCSRF.
- اختُبرت قواعد الكشف بمقاييس الصحيح والكاذب والمفقود، وغياب مرجع القبول، والمعرفات المكررة والمدخلات غير الصالحة. النصوص لا تمر عبر eval.
- اختُبر حفظ المعرفة وإعادة استخدام اللقطة المطابقة، وفشل الشبكة والصيغة مع بقاء الأصل، والبحث الداخلي، وكشف العبث، وتعطيل الجدولة افتراضيًا، واستدراك طلب واحد بدل تكرار الدورات الفائتة.
- اختُبرت سلامة الأدلة وعزل مراجع المشاريع ورفض مسارات الملفات وتجاوز الحصة وكشف العبث بالتدقيق، وإلغاء الجلسة وOrigin/Host/CSRF.
- نجح تصدير نسخة مشفرة واستعادتها. رُفضت كلمة حماية خاطئة ونسخة معدلة ومحاولة خروج من مسار الاستعادة ووجهة موجودة مسبقًا.
- أصلح اختبار المتصفح إعادة رسم مزدوجة بعد التنقل كانت قد تمسح حقل كلمة حماية النسخة بعد كتابته. التحقق يشمل تنزيل النسخة الفعلية بعد التنقل.

اختبارات المصدر والمتصفح لا تثبت جميع الحالات الممكنة أو إتقان التقنيات في العالم.

## حدود التحقق

- ورشة Python رفضت التشغيل503 بسبب منع uid map. هذا اختبار رفض آمن، وليس نجاح عزل أو تنفيذ.
- لم يُختبر استدلال نموذج محلي فعلي؛ اختبارات سياسة موصل AI ليست تقييمًا لجودة النموذج.
- لا صورة OVA أو اختبار VirtualBox أو systemd أو Windows أو هاتف أو عتاد حقيقي.
- CI لإصدارات Python3.11/3.12/3.13 محفوظ كتكوين؛ تحقق المضيف هنا Python3.12، ولم تُشغّل GitHub Actions من هذه البيئة.
- نتائج الإصدارات التاريخية في الملف المرفق لا تخص هذا الكود.

نتائج الاختبار واللقطات المحلية تحت`.state` المستبعد من Git. لا كلمات مرور افتراضية في التطبيق. حفظ تعليمات البيئة في مسودة لا ينشرها ولا يثبت استعادتها في مهمة جديدة؛ تراجع وتحفظ ثم تنشر من إعدادات البيئة.
