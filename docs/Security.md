# نموذج الثقة والحدود

- مالك واحد، وخادم HTTP على loopback فقط؛ ليست خدمة متعددة المستأجرين أو جاهزة للنشر العام. مدير الجهاز/حساب نظام التشغيل يملك الوصول لبياناته؛ لا يعالج التطبيق مضيفًا مخترقًا.
- كلمات المرور مشتقة بـScrypt مع ملح عشوائي. Cookie عشوائي HttpOnly وSameSite=Strict؛ بصمة الرمز في ذاكرة الخدمة، وصلاحية8ساعات. تستخدم عمليات التغيير CSRF وHost/Origin checks وحد دخول8محاولات/دقيقة. Cookie ليس Secure لأن الخدمة HTTP محلية فقط؛ لا تعرضها على الإنترنت أو خلف proxy عام دون تطوير إعداد HTTPS موثق.
- لا تحليلات استخدام أو خطوط/CDN خارجية. جلب المعرفة إلى عنوان عام مسجل فقط، دون بيانات المشروع، يدوي أو بجدولة يفعّلها المالك؛ الجدولة معطلة افتراضيًا ولا تقبل URL بديلًا. يبقى TLS والتحقق من البصمات مفعّلين. موصل AI إلى عنوان IP loopback صريح، دون proxy أو redirects، ويستخدم مقتطفات الأدلة المختارة فقط. النموذج لا يملك صلاحية أدوات.
- المحللات موثوقة ومضمّنة في الكود، وتتعامل مع الملفات كبيانات. ليست محمية بآلة افتراضية لكل تحليل؛ تعمل في عملية الخدمة وبحدود صيغة/حجم، فلا تُستخدم لمعالجة عينات عدائية تتطلب فصل عملية أو VM قبل إضافة عزل مناسب. لا تنفذ ملفات أو أوامر قادمة من AI أو JSON.
- ورشة Python فقط داخل Bubblewrap وnamespaces، ولا fallback. الذاكرة والمعالج والوقت والمخرجات محدودة. mounts للأدوات العامة `/usr,/bin,/lib,/lib64` للقراءة؛ لا تضع أسرارًا شخصية داخلها. عزل namespaces ليس ضمانًا أمام ثغرة نواة.
- الأصل محفوظ منفصلًا، باسم عشوائي وصلاحيات400، وتتحقق بصمته قبل القراءة/التحليل/النسخ. المالك على مستوى OS يستطيع تغييره؛ التحقق يكشف التغير ولا يمنع مدير الجهاز. حصة الأدلة ليست حدًا قاطعًا لكل مساحة النظام والسجلات.
- سلسلة التدقيق تكشف تغيير حدث محلي دون إعادة حساب بقية السلسلة. ليست توقيعًا مستقلاً أو سلسلة حيازة قضائية معتمدة. السجل وبيانات التشغيل غير مشفرين على القرص؛ النسخ المصدّرة وحدها مشفرة.
- نسخة التقرير المنقحة لا تغيّر الأصل ولا تضمن كشف كل سر. راجع أي تقرير قبل مشاركته. تنزيل الأدلة يرسل attachment مع nosniff بدل تنفيذ المحتوى في الصفحة.
- لا فحوص شبكية خارجية، ولا إرسال/تحكم لاسلكي أو وظائف تخفي نشاطًا على أنظمة مستهدفة. استخدم التحليل فقط على البيانات المملوكة أو المصرح بها.

التحديثات التلقائية وتثبيت إضافات الكود وتعدد الأدوار ومفاتيح نشر التحديثات لم تُنفّذ. لا ترفع الأرشيفات أو بيانات التشغيل إلى Git. تعطل الخدمة أثناء تشغيل سير عمل يسجله كـinterrupted عند بدء العملية التالية؛ الاستكمال التلقائي غير منفذ.
