# تعديل النطاق — 0.7.0

طلب المالك إزالة الوكلاء الأربعين من البرنامج واستخدام المساعدين لإنجاز تطوير المشروع خارجه. لذلك أزيلت صفحة الفريق وأدواره وطابوره ومساراته البرمجية من المنتج. لا تُعامل الاستعانة بمساعدي التطوير بوصفها محركًا أو وكلاء مثبتين لدى المالك.

بند N03 في السجل المفهرس أصبح `superseded` لهذا النطاق الملغى، وليس مكتملًا. بقي الملف الأصلي `Requirements-Source.md` مطابقًا للبايت ولم تُحذف منه المعلومات التاريخية.

يبقى موصل المحادثة المحلي الاختياري مستقلاً؛ يتطلب محركًا ونموذجًا على جهاز المالك، ولم يثبت استدلال نموذج حقيقي في بيئة الاختبار. لا تنفذ مخرجات النموذج كودًا أو أوامر نظام.

نتائج الإصدار 0.6 وتقاريره تاريخية وتتضمن الفريق الذي ألغي؛ لا تثبت اختبارات النسخة الحالية. سُحبت أرشيفات المصدر وwheel للإصدار 0.6 من شجرة التنزيل الحالية حتى لا يعيد تثبيتها المالك بالخطأ. يحتفظ Git بتاريخ الإصدار والتقارير دون إعادة كتابة التاريخ؛ قواعد بيانات المالك وأدلته لا تُحذف بسبب هذا التغيير. تبقى حزمة 0.5 التاريخية مفهرسة بوصفها تاريخية.

التقارير وملفات الكود تُحفظ داخل المستودع الخاص فقط. بيانات التشغيل والرموز والأدلة وأوزان النماذج لا تُرفع.
