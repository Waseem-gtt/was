## حزمة 0.5.0 التاريخية

تعود الحزمة إلى الالتزام `de4622f60580bb456d35ca3b70d31de3e5672236`. جرى التحقق من تطابق جميع ملفات أرشيف المصدر البالغ عددها53ملفًا مع شجرة Git لذلك الالتزام، ومن تطابق ملفات حزمة `cyber_platform` داخل wheel مع المصدر نفسه. تحتفظ الحزمة بالتاريخ الأصلي ولا تتضمن التغييرات التي تلت ذلك الالتزام. [بيان المنشأ](../releases/0.5.0/provenance.json) يحدد الحجم والبصمة لكل ملف؛ [البصمات](../releases/0.5.0/SHA256SUMS) تساعد على اكتشاف التغيير، وليست توقيع ناشر.

داخل مجلد `releases/0.5.0` يمكن التحقق محليًا بالأمر `sha256sum -c SHA256SUMS`. هذه الملفات محفوظة في شجرة Code؛ لا يعني وجود المجلد إنشاء إصدار في تبويب GitHub Releases.

## حدود التقدم

إضافة معلومات الملف وفهرستها لا تعني تنفيذ كل متطلب. إصدار0.5 يضم21أداة و22قسمًا و109منصات، وفحوص صيانة وإصلاح صلاحيات محدودًا ومسار ترقية متحققًا. لا تعني هذه الأعداد نسبة إنجاز للرؤية الكاملة. لم تُختبر صورة OVA أو استدلال نموذج محلي حقيقي أو جلسة سطح مكتب رسومية؛ ولا يوجد إصلاح شامل مستقل لكل أعطال Linux أو توقيع ناشر/TUF في حزمة0.5. راجع حالة التنفيذ الحالية لمعرفة الإضافات اللاحقة وحدودها.

ملخص0.5 يوثق106اختبارات لكل نسخة Python و18مجموعة متصفح في بيئة الاختبار آنذاك. نجاحها محليًا لا يثبت نجاح Actions البعيد أو خلو المشروع ونظام التشغيل من جميع الأخطاء.
