# F04 — مكتبة قواعد كشف قابلة للاختبار: مكتمل

أكمل0.18البندF04بنص ملف المتطلبات: مصدر وترخيص ونسخة وfixturesوتغطية وإعادة اختبار. ذكر الملفSigmaمرجعًا مرشحًا؛ لا يجعل اكتمال محركSigmaكامل أو مستشعر حي شرطًا لهذا البند. الوظيفة المنفذة مكتبة قواعد مطابقة حقول موثقة، قابلة للتوسع بقواعد المالك ضمن الصيغة المعتمدة، مع اختبار فعلي لنسخها الحالية.

## عناصر القبول

| المتطلب | ما يعمل |
|---|---|
| مصدر وترخيص ونسخة | بيانات صريحة لكل قاعدة مدمجة أو قاعدة مالك، مع معرف ثابت وإصدارات ومراجعات وبصمات |
| عينات اختبار | عينات مدمجة أصلية، وعينات مالك بملفJSONأصلي محفوظ وتسميات مطابقة موجبة وسالبة صريحة |
| ربط العينة بالإصدار | إيصال ثابت يربط أصل الملف وبصمته ونسخة القاعدة وبصمتها والتوقعات ومراجعة العينة |
| قياس التغطية | جميع القواعد الحالية ظاهرة: مجتازة أو فاشلة أو بلا عينة أو بعينة لإصدار قديم؛ لا تُحسب القاعدة غير المختبرة مجتازة |
| إعادة اختبار | تشغيل جديد في عاملPythonمحدود لكل دفعة، معTP/FP/FN/TNوprecision/recallوتقرير ثابت قابل للعرض والتصدير |
| تحقق المصدر والاستعادة | فحص البصمات والتدقيق والإصدارات قبل التشغيل وبعده، وتراجع ذري عند فشل التسجيل، واستعادة مشفرة مختبرة |

## الاستخدام

اختر مشروعًا ثم «مكتبة الكشف». في «عينات القواعد وتغطيتها وإعادة اختبارها» شغّل اختبار جميع القواعد. للقواعد الثماني المدمجة عينات منشورة أصلية تلقائيًا؛ ليست قياسًا ميدانيًا لجهازك.

بعد إضافة قاعدة مالك من المحرر الموجود، افتح «عينة مرجعية لقاعدة المالك»، واختر القاعدة وملفJSONأصليًا ثم فهارس الأحداث المطابقة المتوقعة، مثل`[0]`. الفهارس تبدأ من الصفر، وبقية الأحداث تُعد أمثلة سالبة وفق تسمية المالك. يلزم مثال موجب وآخر سالب على الأقل. يمكن للتوقعات أن تكشف فشل القاعدة؛ لا يحوّل النظام التوقعات لتطابق تنفيذها.

أعد اختبار المكتبة لعرض فجواتها ونتائجها. إصدار قاعدة جديد يجعل العينة السابقة متقادمة حتى تسجيل عينة لهذا الإصدار. التقرير المنزّل ملخص مشتق ومراجع وبصمات وبيانات قواعد؛ لا ينسخ ملف الأحداث الخام. التقارير المحفوظة تاريخية؛ عرض تقرير قديم ليس إعادة تنفيذ ولا حماية حية.

## العقد والحدود

صيغة العينة مصفوفة أحداثJSONأو`was.event/1`بحقل`events`؛ ليست برنامجًا ولا مصدر أوامر. لا تُقبل مظروفات أدلة تدعي مصدرية تحويل بوصفها إثباتًا جديدًا. مصدر التسميات هو مالك البيانات؛ لا يعني ذلك حقيقة مستقلة عن صحة هجوم.

حتى8قواعد مدمجة و50قاعدة مالك، و10مراجعات للقاعدة، و20مراجعة لعينة كل قاعدة، و20تقرير قبول لكل مشروع. الملف1ميبيبايت وحتى1000حدث للعينة، والدفعة كلها4ميبيبايت و10000حدث. يعمل العامل بحد3ثوانٍ للمعالج و384ميبيبايت للذاكرة و3ثوانٍ انتظار؛ لا عزل كامل للشبكة والملفات. تجاوز الميزانية أو فشل العامل يرفض التشغيل دون إعلان نجاح.

ربط إيصالات العينات والفهارس والتدقيق ذري. يُقارن الفهرس بكامل أحداث إنشاء القواعد والعينات؛ حذف سجل أو الرجوع إلى فهرس قديم لا يعيد اعتماد إصدار سابق بصمت. المصدر والأدوات والقاموس ومحرك التنفيذ جزء من بصمة التشغيل. لا يثبت ترخيص المصدر المعلن صلاحية قانونية لكل بيانات يضيفها المالك، ولا تُنفّذ روابط المصدر أو تعليمات الملف.

الواجهات: `GET /api/detection/acceptance?project=ID`، و`POST /api/detection/fixtures/register`بحقول`project_id,rule_id,evidence_id,expected_indexes`، و`POST /api/detection/acceptance/run`بحقل`project_id`، و`GET /api/detection/acceptance/report?project=ID&id=EID`. كلها تتطلب حساب المالك؛ الحفظ والتشغيل محميان بـCSRFوقفل العمليات الثقيلة.
