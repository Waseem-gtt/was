# تحقق الإصدار 0.10.0 — 19 أكتوبر 2026

نجح **241 اختبارًا** على كل من CPython 3.11.17 و3.12.14 و3.13.5. أضيف 52 اختبارًا: 13 لمحولات الأحداث، و16 لمكتبة الكشف، و12 للتغطية الدفاعية، و5 لحفظ الأحداث والتحقق من مصدرها، و5 لواجهات HTTP، واختبار استعادة مشفرة يربط الوظائف الجديدة.

اختُبرت محولات Windows JSON وRFC5424 وCSV بعامل حقيقي، مع رفض الدفعة المعيبة كاملة، والحدود والصيغ الصارمة وحفظ الأصل. تشمل فحوص النشر التراجع عن الملفات والبيانات والعلاقات والتدقيق عند فشل الحفظ؛ لا توجد نتيجة نصف محفوظة معلنة كنجاح. يُعاد تشغيل المحول عند استخدام دليل موحد في الكشف، وتُرفض مصادره أو بصماته المتغيرة.

اختُبرت القواعد المدمجة الثماني ببيانات اصطناعية ذات توقعات مرجعية صريحة، والحالات الصحيحة والكاذبة والمفقودة، والقيم غير المعرّفة لـprecision/recall، وغياب التوقعات أو نقصها، ومراجعات قواعد المالك وحدودها وثباتها. تتحقق إعادة التنفيذ من المصدر والقواعد والمكتبة والمحرك؛ تغير المحرك أثناء الاختبار يمنع نشر نتيجة منسوبة إلى إصدار آخر.

اختُبرت الأصول والتقييمات والفجوات والتعارض، ورفض الأدلة التابعة لمشروع آخر والتقارير المتلاعب بها، وعدم اعتبار ملف عادي أو توقعات فارغة دليل حماية. حالة الدعم تحتاج فرص كشف موجبة لكل قاعدة مع نتائج مطابقة. حد عرض التغطية ثلاثة تقارير كشف مختلفة مع ميزانية معلنة؛ البقية غير متحققة، ولا يُعلن دعمها. يزيل الحذف الارتباط فقط ويحفظ الأدلة.

أصلح الإصدار ترتيب قفل المهام الثقيلة: تُستكمل العملية ويُحرر القفل قبل إرسال الاستجابة، حتى لا يُرفض طلب لاحق لمجرد تأخر التنظيف بعد اكتمال العملية. يثبت اختبار مخصص هذا الترتيب. لا تُعطّل سياسة CSP؛ انتظار جاهزية الواجهة في الاختبار لا يستخدم تقييم نص داخل الصفحة.

نجحت **25 مجموعة متصفح** دون أخطاء JavaScript، مع تحقق 16 صفحة بعرضي 320 و390 بكسل. تشمل توحيد الأحداث والتصدير، واستيراد مثال الكشف واختبار قواعده، وحفظ مراجعتين لقاعدة مالك وبيان عدم تقييمها دون توقعات، ودورة أصل غير مختبر ثم ربط اختبار صالح ثم التصدير وإزالة الارتباط وإعادة تحميل الحالة.

نجح Bandit دون نتائج غير معالجة أو أخطاء تحليل، وpip-audit للاعتمادات الإنتاجية الثلاثة المقفلة دون ثغرات معروفة وقت الفحص. نجحت صياغة JavaScript وBash وتطابق الملف الأصلي البالغ 173726 بايت. بُنيت حزمة wheel وثُبتت في مسار مستقل واختُبرت عبر HTTP: الصحة والمصادقة والتحليل والصيانة والبصمات والتوقيع المؤقت ومركز الجودة بحالاته الـ48 والمحولات ومكتبة الكشف والتغطية والتدقيق وموصل محادثة اصطناعي.

هذه فحوص محلية؛ لم تُقرأ نتيجة GitHub Actions البعيدة بسبب سياسة شبكة API. لا نموذج محلي حقيقي أو OVA أو جمع سجلات حي أو دعم OCSF/Sigma/D3FEND كامل. التغطية ثابتة مرتبطة بتجارب محفوظة وتسميات بيانات يقدمها مصدرها، وليست إثبات حماية أصل في الواقع. لم تُنشأ مفاتيح مالك أو ناشر حقيقية، وحزمة التسليم غير موقعة بمفتاح ناشر. تبقى F03 وF04 وN06 جزئية، مع تقدم موثق، ولا توجد نسبة اكتمال كلية مختلقة. راجع [حالة التنفيذ](Implementation-Status.md).
