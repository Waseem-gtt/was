# تسليم0.20 — الوظائف المنفذة والأقسام غير المكتملة

نفذ هذا الإصدار تشغيل إضافاتWasmموقعة فعلية: ثقة ناشر صريحة، واختبار وعزل وتثبيت وتفعيل وإيقاف واستبدال واستعادة إصدار، وتشغيل ملف مختار وحفظ النتيجة ومصادرها. [العقد والاستخدام](Plugin-Installations.md) و[التحقق](Validation-0.20.md).

**لم يكتمل قسم رئيسي أو دفعة كاملة في هذا الإصدار.** قسم إدارة المنظومة ما زال يحتاج الموارد والتحديث والصيانة الشاملة، وبقية الأقسام لها نواقصها أدناه.

وفق [توجيه المالك](Completion-Policy-0.20.md)، عاد عرضE02وBASE.13وF03وF04وF06إلىجزئيحتى إنهاء وظائف أقسامها. أبقيت وظائفها واختباراتها، وأضفت تبعيات الاكتمال المفتوحة. لا تمثل التسمية السابقة اكتمال قسمها.
