# تحقق الإصدار 0.11.0 — 20 أكتوبر 2026

نجح **311 اختبارًا** على كل من CPython 3.11.17 و3.12.14 و3.13.5. أضيف 70 اختبارًا: 18 للمحرك المتفرع، و14 للقوالب وإثبات ربطها، و17 لفحص التغطية الكامل، و13 لتقارير المشروع، و7 لواجهات HTTP وتكامل الوظائف، واختبار استعادة مشفرة للوظائف الجديدة.

تغطي فحوص الخطط ترتيب DAG ورفض الدورات، والفروع الصريحة للنجاح والفشل وانتشار التجاوز، وعدم احتساب العقد المتخطاة كنجاح. جُربت سلاسل بعمال حقيقيين، والتوقف والاستكمال وإعادة فتح التخزين، ورفض تكرار عقدة انقطع نشرها، والتزامن، ومعاملة نشر النتيجة والتقدم والتدقيق، والتراجع بعد فشل الحفظ. عُدلت المصادر والنتائج والمحرك وسجلات الحالة عمدًا للتأكد من منع الاجتياز الكاذب.

نُفذت أمثلة القوالب الثمانية عبر عمال حقيقيين. تشمل الفحوص عزل المشاريع، وحدود المراجعات وثباتها، ورفض الأوامر والصلاحيات وحقول غير مسموحة، وحفظ `plan-instantiation` والتحقق منه، واحتفاظ المراجعات التاريخية للمالك بمصدرها. تعديل الخطة يمنع نسبتها إلى إثبات القالب القديم؛ تبقى الخطة اليدوية ممكنة دون نسبة كاذبة.

اختُبرت أربعة تقارير كشف مختلفة، متجاوزة حد العرض السريع السابق، عبر مراحل التقييم وإعادة قراءة ملفات الإثبات. شملت الفحوص تغير النطاق والمحرك والقواعد والأصول والملفات، وانقطاع حالة جارية، وحدود الدفعات والاحتفاظ، والتحقق الصارم من ترابط الملفات والحالات حتى عند إعادة حساب بصمة سجل متلاعب به. النتيجة لقطة تاريخية متتابعة `snapshot_only`، وليست حماية حية أو لقطة ملفات ذرية.

تغطي التقارير حفظ مرجع الدليل والخطة والتغطية، واستبعاد بايتات المصدر الخام، وترميز نصوص HTML وسياسة بلا JavaScript، والتغير والفقد وعزل المشاريع، ورفض النطاق الفارغ والتقارير المتداخلة، والحساب المسبق لميزانية قراءة إثبات الخطط، وعدم قراءة ملف تغير حجمه قبل رفضه. اختُبر حد الاحتفاظ دون حذف صامت والتراجع الذري عند فشل نشر التقرير. نجحت استعادة النسخة المشفرة مع القالب وإثباته والخطة واللقطة والتقرير وسلسلة التدقيق.

نجحت **30 مجموعة متصفح** دون أخطاء JavaScript، مع تحقق 18 صفحة بعرضي 320 و390 بكسل. تشمل إنشاء خطة من قالب دون تشغيل تلقائي، ودفعة ثم إيقاف وإعادة تحميل واستكمال وتصدير، ومراجعتين لقالب مالك، وفرع فشل صريح مع تجاوز فرع النجاح، وفحص تغطية كامل محفوظ، وتقرير يجمع المصادر والخطة واللقطة مع تنزيل JSON وHTML وإعادة فحص المراجع وإعادة فتح التقرير بعد التحميل.

نجح Bandit دون نتائج غير معالجة أو أخطاء تحليل، وpip-audit للاعتمادات الإنتاجية الثلاثة المقفلة دون ثغرات معروفة وقت الفحص. نجحت صياغة JavaScript وBash وتطابق الملف الأصلي البالغ 173726 بايت. اختبرت الحزمة المثبتة مستقلة عبر HTTP، بما فيه الميزات السابقة وحالات الجودة الـ48 والخطط والقوالب وإثبات المصدر وفحص التغطية والتقرير بصيغتيه. اختبارات المحادثة والتوقيع تستخدم بدائل ومفاتيح اصطناعية فقط، وليست نموذجًا محليًا أو مفتاح مالك حقيقيًا.

أضيفت أداة تسليم Python تتحقق من إصدار wheel والتقرير وتطابق كل ملف مصدر مختار وملف حزمة مع التزام Git، وتولد المصدر والبرنامج والبيان والبصمات دون نشر أو توقيع تلقائي. تستثني `releases/` من المصدر لمنع تداخل الأرشيفات التاريخية؛ يبقى التاريخ في المستودع. بيان منشأ حزمة التسليم يوثق الالتزام والاستثناء والأعداد الفعلية بعد تشغيل الأداة.

النتائج محلية؛ لم تُقرأ نتيجة GitHub Actions البعيدة بسبب سياسة شبكة API. لا تنفيذ متوازٍ للخطط أو عامل خلفي تلقائي أو إعادة عقدة مجهولة المصير، ولا استعادة حالة محاكاة أو توليد إضافات كود أو عودة للمختبرات والوكلاء داخل المنتج. نجاح التنفيذ دون توقعات مرجعية ليس تقييم جودة، ومطابقة مراجع التقرير ليست اعتماد تحقيق. لا نموذج حقيقي أو OVA متحقق أو اكتمال لجميع التخصصات؛ [حالة التنفيذ](Implementation-Status.md) تبقي الفجوات معلنة.
