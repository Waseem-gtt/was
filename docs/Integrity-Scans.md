# فحص الأدلة على دفعات — 0.7

من صفحة «التحديث والصيانة» اختر جميع المشاريع أو مشروعًا واحدًا، ثم «بدء فحص البصمات». تُحفظ لقطة مرتبة من معرفات الأدلة ومشاريعها وأحجامها وبصماتها. «فحص الدفعة التالية» يتحقق من100ملف أو64MiBأو ثلاث ثوانٍ من قراءة الأدلة كحد أقصى لكل دفعة. عدد الأدلة الكلي حتى10000؛ يمكن اختيار مشروع أصغر إذا تجاوز النطاق الحد. يُحتفظ بحد20عملية، مع إزاحة أقدم نتيجة نهائية عند الحاجة وحماية الفحوص النشطة من الإزاحة.

تستطيع التنقل ثم العودة أو إعادة تحميل البرنامج واختيار «فحص محفوظ» لمتابعته. الخادم يحفظ موضع التقدم؛ لا يقبل الطلب مؤشّرًا أو نتيجة يفرضها المتصفح. يبقى `passed=false` حتى نهاية الفحص النظيفة وثبات لقطة بيانات الأدلة. يستمر عبر الأدلة المفقودة أو التالفة لتسجيل الملاحظات دون حذفها أو إصلاح محتواها. الملفات الجديدة أو تغير بيانات النطاق قبل النهاية يجعل النتيجة غير ناجحة ويستلزم فحصًا جديدًا للنطاق الحالي.

تُقرأ الأدلة عبر واصفات مثبّتة دون اتباع الروابط الرمزية، ويُرفض الربط الصلب وتغير الحجم أو الهوية أو البصمة أثناء القراءة. تُراجع هوية مجلد البيانات ومجلد الأدلة وقاعدة البيانات مقارنة بوقت فتحStore. تبديل التخزين يرد فشلًا مؤقتًا بحالة حفظ`blocked_unsafe_storage`دون كتابة سجل أو تدقيق إلى موقع غير متحقق؛ تبقى آخر نقطة تقدم محفوظة كما كانت. تلف سجل التدقيق يمنع بدء الفحص أو تقدمه. يتحقق الاستكمال من بصمة اللقطة المحفوظة واتساق عداداتها.

الفحص قراءة فقط؛ لا يغير محتوى الأدلة أو صلاحياتها. يُحفظ التقدم وعمليات التدقيق في قاعدة البيانات عند سلامة التخزين. حد الثلاث ثوانٍ يخص قراءة الأدلة، ولا يشمل كامل تحقق التدقيق أو حفظSQLite. هذه لقطة تُقرأ على مراحل، وليست لقطة نظام ملفات ذرية: لا تضمن أن ملفًا سبق فحصه لم يتغير لاحقًا، ولا تفحص ملفات خارج سجل الأدلة. صلاحية مدير نظام مخترق خارج حد الثقة المحلي.

## الواجهات المحمية

- `POST /api/integrity/start`: `{ "project_id": null }` لجميع المشاريع، أو معرف مشروع.
- `POST /api/integrity/advance`: `{ "scan_id": "…" }` للدفعة التالية بالحدود الثابتة.
- `GET /api/integrity?scan=ID`: التقدم المحفوظ، دون قائمة اللقطة الداخلية.
- `GET /api/integrity/history`: الفحوص المحفوظة لفتحها من الواجهة.

يلزم تسجيل الدخول لكل واجهة، وCSRFلعملياتPOST. يشارك البدء والتقدم قفل التنفيذ مع التحليل والصيانة والجدولة. لا ينفذ هذا النظام تعليمات نموذج ذكاء أو أوامر نظام.
