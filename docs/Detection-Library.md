# مكتبة الكشف الدفاعي

تضيف النسخة0.10 مكتبة قواعد ذات إصدارات واختبارات محفوظة، ضمن F04. هذه مطابقة AND لحقول JSON مسطحة بقيم وأنواع دقيقة؛ لا تستخدم regex أو eval أو YAML، ولا تدعي دعم Sigma كاملًا أو مراقبة حية.

## المكتبة والبيانات المرجعية

تتضمن المكتبة8 قواعد أصلية اصطناعية منشورة بـCC0-1.0: فشل الدخول، تغيير صلاحية إدارية، تعطيل التدقيق، تعطيل الجدار الناري، تنبيه برمجية ضارة، رفض وصول ملف، إنشاء حساب، وتغيير إعداد أمني. هذه أمثلة تعليمية ضيقة وليست مؤشرات كافية وحدها على اختراق. تُعرض حقول المصدر والترخيص والإصدار والاختيار.

يتضمن `detection_packs.json` مجموعة أحداث اصطناعية وتسميات مرجعية صريحة لكل قاعدة. يمكن استيراد `fixtures[].input` كدليل JSON أصلي ثم تشغيل القواعد المختارة. لا تُطبَّق تسميات المثال تلقائيًا على أدلة المالك. مثال مبسط:

```json
{"schema":"was.event/1","events":[{"action":"login","outcome":"failure"}],"expected_matches":{"was-login-failure":[0]}}
```

يمكن تقديم مصفوفة أحداث دون تسميات. تبقى نتيجتها `not_evaluated` و`passed:false`، حتى عند العثور على مطابقات. يقرأ الاختبار التسميات من الدليل نفسه فقط، ولا يقبل قائمة حقائق من حقول طلب HTTP منفصلة. التسميات ادعاء يقدمه مصدر البيانات، وليست حقيقة مستقلة ثبتت من العالم الحقيقي.

## قواعد المالك

تحفظ القاعدة بستة حقول بالضبط: `id,title,version,license,source,selection`. المعرف أحرف ASCII صغيرة وأرقام ونقطة وشرطة، حتى80 حرفًا؛ الإصدار ثلاثة أجزاء عددية. يتضمن الاختيار1–20 حقلًا، بقيم JSON مفردة. الأنواع دقيقة: `true` لا يطابق `1`. لا تقبل القاعدة صلاحيات أو أوامر تنفيذ أو شبكات.

لا يمكن استبدال بادئة `was-` المحجوزة للمكتبة المدمجة. يمكن للمالك حفظ50 معرفًا لكل مشروع، وحتى10 مراجعات لكل معرف. رقم إصدار محفوظ لا يُستبدل. كل مراجعة دليل `detection-rule` مستقل، مرتبط بسابقه، مع بصمة التعريف. يُحتفظ بالأصل ويُستخدم أحدث إصدار للاختبارات الجديدة؛ تغيير القاعدة يجعل تقييم التغطية المبني على إصدار سابق قديمًا حتى يعاد اختباره.

## التنفيذ والنتائج

يشغّل الاختبار المحرك الموثوق في عامل مستقل بحدود CPU والذاكرة والوقت الموجودة. الحد10000 حدث و50 قاعدة و4MiB للمدخل والتقرير المحفوظ. لا تُنفّذ الملفات المستوردة. تُرفض مفاتيح JSON المكررة والأرقام غير المنتهية والتسميات المكررة أو خارج النطاق.

يحفظ دليل `detection-test` نتائج المطابقة وTP/FP/FN/TN وprecision وrecall، وتعريفات القواعد الكاملة وإصداراتها، وبصمة المصدر والمكتبة والمحرك. المقام الصفري ينتج `null` ولا يتحول إلى نسبة نجاح. النجاح الكلي يتطلب تسميات لكل قاعدة مختارة ومطابقة نتائجها جميعًا؛ وجود بعض التسميات فقط لا يمرر الاختبار كله.

للربط بخريطة التغطية يعيد `verify_report` قراءة الأدلة والتحقق من البصمات والتعريفات الحالية وإعادة التنفيذ بعامل محدود. لا يقبل قيمة `passed` محفوظة وحدها. التقرير السليم لا يدعم التغطية إلا إذا نجحت كل القواعد مع وجود موجب صحيح واحد على الأقل لكل قاعدة؛ نجاح حالات سلبية فقط لا يثبت قدرة كشف. تغير المصدر أو القاعدة أو المحرك أو التلاعب بالنتيجة يجعل الحالة قديمة. هذا تحقق مرجعي على مجموعة معينة، وليس إثبات تغطية هجوم كامل.

حفظ القواعد والتقارير يراجع سلسلة التدقيق وهوية التخزين، ويستخدم عملية قاعدة بيانات واحدة مع تنظيف ملف الدليل عند الفشل. لا تُرفع أدلة التشغيل أو قواعد المالك إلى GitHub.
