# واس — منصة البحث السيبراني المحلية

[فهرس ملفات المشروع والتقارير وحزم التسليم](docs/Project-Index.md) · [مكانها في حساب GitHub](docs/GitHub-Guide.md).

تنفيذ جديد من الصفر على Linux، اعتمادًا على [ملف المتطلبات المرفق](docs/Requirements-Source.md). المستودع كان فارغًا؛ ملفات وإصدارات OVA السابقة المذكورة في الوثيقة لم تكن متاحة، لذلك لا تُنسب نتائجها واختباراتها إلى هذا الكود.

تحتوي النسخة **0.11.0** على واجهة عربية RTL، حساب مالك، مشاريع، أدلة أصلية ببصمات SHA-256، و21 أداة تحليل واختبار قواعد كشف، وسير عمل بمعايير قبول واستكمال متحقق، ومقارنة نتائج، وعلاقات أدلة، وسجل تدقيق، ونسخ احتياطية مشفرة. تشمل [الصيانة](docs/Maintenance.md) تحققًا قبل إصلاح الصلاحيات وبعده وتراجعًا عند الفشل. مشغّل لينكس وترقية الإصدارات لا ينفذان تعليمات النموذج. أُلغي نظام فريق الوكلاء داخل البرنامج بطلب المالك؛ المساعدون المستخدمون لتطوير المشروع خارج التطبيق. يبقى موصل المحادثة المحلي الاختياري مستقلًا عن الفريق الملغى. [تعديل النطاق 0.7](docs/Scope-Update-0.7.md).

أضاف إصدار0.11 [خطط تحليل متفرعة محفوظة](docs/Workflow-Plans.md)، و[8قوالب قابلة لإعادة الاستخدام](docs/Plan-Templates.md) مع إثبات المصدر ومراجعات المالك، و[فحص تغطية كاملًا على دفعات](docs/Coverage-Scans.md)، و[تقارير مشروع JSON وHTML](docs/Project-Reports.md) تجمع المراجع دون نسخ محتوى الأدلة الأصلية. التنفيذ يدوي ومتتابع ومحمي؛ لا تشغيل أوامر أو إعادة نظام الوكلاء أو طبقة المختبرات.

أضاف إصدار0.10[محولات الأحداث](docs/Event-Adapters.md) لـWindows JSON وSyslog RFC5424 وتدفقاتCSVمع حفظ الأصل ومصدر النتائج، و[مكتبة كشف](docs/Detection-Library.md) من8قواعد أصلية ومراجعات مالك واختبارات ذات مقاييس، و[تغطية دفاعية](docs/Defense-Coverage.md) تربط الأصول والتهديدات والإجراءات بالأدلة وتظهر الفجوات. الصفحات الثلاث تعمل بحساب المالك فقط، ولا تتصل بأجهزة أو تثبت فعالية دفاعات العالم الحقيقي.

أضيف في0.9[مركز جودة الأدوات](docs/Quality-Center.md) لاختبار المحللات بحالات مرجعية اصطناعية، وحفظ التقدم والتقارير ومقارنة التراجع والتحسن. لا يقرأ أدلة المالك ولا يدعي تقييم جميع التخصصات.

أضيف في0.8[توقيع الإصدارات والتحقق منها](docs/Signed-Releases.md) بـPythonوEd25519، مع مفاتيح ثقة يحددها المالك، وانتهاء صلاحية، وتسلسل مانع للتراجع، وربط بالتزام المستودع. بعد تثبيت سياسة التوقيع يُرفض التفعيل غير الموقّع. لا يُنشأ مفتاح مالك افتراضي، ولا يُدّعى أن حزم التسليم موقعة تلقائيًا.

حسب تعديل المالك بتاريخ18أكتوبر2026 أصبح الهيكل **22 قسمًا ←109 منصات فرعية ← أدوات وتقنيات**. أُزيلت طبقة المختبرات من بيانات التطبيق والواجهة. حُفظت المنصات الأصلية69وأضيف20مسار حماية و20مسار تعلّم أخلاقي. يحتوي كل مسار تعلّم درسًا ومثال أداة على بيانات اصطناعية وتقييمًا محفوظًا؛ لا يُعد ذلك إتقانًا للتخصص أو تصريحًا لاختبار جهة خارجية. [التعديل المعتمد وحدود النسخة](docs/Scope-Update-0.2.md).

المعرفة ذات مصادر عالمية، والتطبيق وبياناته خاصان بالمالك. توفر صفحة **المعرفة العالمية** جلب فهرس CISA KEV والبحث في لقطة محفوظة داخل المشروع. لا تُرسل بيانات المشروع أو أسئلة البحث إلى المصدر. يمكن للمالك تفعيل فحص كل60ثانية أو تغيير الفاصل أو إيقافه؛ الجدولة معطلة افتراضيًا وتعمل ما دامت الخدمة تعمل. تحفظ بصمة المصدر وإصداره ووقت الفحص ووقت تغيره منفصلين، وتبقى اللقطة السابقة مع علامة قديمة عند الفشل. يلزم السماح بـ`raw.githubusercontent.com` على HTTPS في البيئة التي يجري فيها الجلب. روابط التقنيات العالمية في المنصات مراجع، وليست وعدًا بمتابعة كل تقنيات العالم تلقائيًا أو تثبيت أدواتها.

الإصدار **0.3.0** يضيف صفحة **ملف المشروع ومتطلباته**: الملف المرفق كاملًا، مفهرس إلى411 مقطعًا مع أرقام أسطر، و61 بندًا مرتبطًا بالمصدر وحالة التنفيذ. يمكن البحث في جميع المعلومات، وعرض الأصل وتنزيله مطابقًا بالبايت، وتصدير السجل بما فيه35 رابطًا و28 اسم ملف ورد في النص. يمكن إضافة الأصل كمرجع خاص للمشروع المختار دون تكرار نسخة مطابقة. تبقى حالة القدرات غير المنفذة واضحة؛ إدراج المعلومات لا يحول الادعاءات التاريخية إلى نتائج لهذا الكود، ولا يعيد المختبرات التي ألغاها المالك. [تفاصيل حفظ الملف](docs/Source-Integration.md).

## لغات التنفيذ

Python هي اللغة الأساسية لمنطق التطبيق والتحليل والصيانة والأتمتة والاختبارات. تُستخدم HTML وCSS وJavaScript لواجهة المتصفح، وBash لسكربتات تشغيل وتثبيت لينكس الصغيرة. أي لغة إضافية تحتاج سببًا تقنيًا واضحًا؛ لا تُضاف لغات أو بيئات تشغيل لمجرد التنويع. تبقى اختبارات الوظائف والأمان مطلوبة مهما كانت اللغة.

## التشغيل على Linux

المتطلبات: Python 3.11 أو أحدث مع `venv` و`pip`. على Debian/Ubuntu يمكن لمدير الجهاز تثبيت `python3 python3-venv python3-pip bubblewrap util-linux` من مستودعات النظام الموثوقة. Bubblewrap اختياري لورشة الأكواد، وغيابه لا يمنع تحليل الملفات.

من جذر المستودع:

```bash
bash scripts/install.sh
bash scripts/start.sh
```

افتح متصفح الجهاز على المنفذ المحلي8080. عند أول تشغيل، اقرأ رمز التهيئة من ملف `setup-token` داخل مجلد بيانات التطبيق على جهازك، وأدخله مع كلمة مرور المالك في صفحة التهيئة. الملف بصلاحيات0600 ويحذف بعد نجاح إنشاء المالك. لا ترسل الرمز في المحادثة أو ترفعه إلى Git. الحسابات المنشأة سابقًا لا تحتاج إلى رمز جديد. الخادم يستمع إلى `127.0.0.1` فقط؛ بياناته الافتراضية في `~/.local/share/was-platform` خارج المستودع. تغييرها:

```bash
bash scripts/start.sh --data /path/to/private-data --port 8080 --quota 2000000000
```

1. أنشئ مشروعًا.
2. ارفع ملفًا من صفحة الأدلة، أو أضف عينة تعليمية من أداة.
3. اختر محللًا متوافقًا مع صيغة الملف. لكل أداة وصف للمدخل وحدود معلنة.
4. أضف معيار قبول مثل `{"ipv4.0":"192.0.2.1"}` أو اتركه فارغًا لتشغيل غير مقيّم.
5. راجع نتيجة المهمة وعلاقتها بالأصل. فشل القبول يوقف الخطوات التابعة ويحفظ النتيجة الفاشلة.

من صفحة سير العمل، يمكن **استكمال** مهمة فاشلة أو متوقفة: عدّل الخطوات غير المنجزة فقط. يتحقق الخادم من خطة الأصل وبصمات الملفات والنتائج والمحرك، ويعيد استخدام المنجز دون إعادة تشغيله. تغير المحرك أو تلف نتيجة أو تعديل خطوة منجزة يمنع الاستكمال؛ تبقى إعادة التشغيل الكامل متاحة. تنشأ مهمة جديدة مرتبطة بالأصل مع عداد منفصل للخطوات الجديدة والمعاد استخدامها.

في الصفحة نفسها، يمكن مقارنة نتيجتي تحليل من الأداة نفسها. تحفظ الفروق البنيوية مع بصمتي المصدر وعلاقات الأدلة. الحد100 فرق و10000 عقدة وعمق64؛ تجاوزها يظهر «مقارنة جزئية» ولا يُعلن تساويًا. الفرق وحده لا يثبت صحة نتيجة أو أمن إصدار.

تنفذ المحللات على الملفات داخل عامل Python جديد بحد384MiB ذاكرة و3ثوانٍ CPU و10ثوانٍ انتظار نتيجة. هذا حد موارد للكود الموثوق؛ لا يحول العامل إلى VM أو namespace ملفات/شبكة، ولا ينفذ ملفات المالك ككود.

حد رفع الملف 16 MiB، وحد مدخل المحلل 4 MiB. حصة الأدلة الافتراضية 2 GB مع احتياطي قرص 256 MiB. حد المشروع 35 GB هدف تصميم وارد في آخر تحديث للمتطلبات، وليس قياسًا لصورة Linux متكاملة أو ضمانًا لاستيعاب جميع الأدوات.

## الأدوات المتاحة

استخراج IOC، مراجعة رؤوس HTTP، توحيد أحداث بصيغة محلية، بصمات الملفات، رؤوس ELF/PE وسلاسل نصية، إحصاء تدفقات CSV، مراجعة حسابات JSON، مراجعة وصف حاوية، جرد CycloneDX/SPDX، سجلات TLV، جرد خوارزميات نصي، entropy وتواقيع Firmware، توأم حراري مبسط، DFT لعينات قصيرة، جودة تسلسل قياسات CSV، CAN كلاسيكي من candump، رؤوس CCSDS الأساسية، تدقيق وجود مقتطفات AI، تنقيح نصي، والتحقق من بيان إضافة.

أضيفت أداة قواعد كشف بصيغة `was.rules/1` لمطابقة حقول أحداث مقدمة واختبار النتائج المتوقعة وقياس الصحيح والإنذارات الكاذبة والمفقود. ليست محرك Sigma كاملًا ولا مستشعر مراقبة حيًا. تستخدم منصات الحماية والتعلم الأدوات المشتركة نفسها؛ لا يحسب ربط الأداة في عدة منصات كأدوات جديدة مثبتة.

هذه أدوات فعلية بحدود محددة، وليست بديلًا عن الأدوات المؤسسية لكل قسم. لا فحص شبكة أو بث أو تحكم بأجهزة، ولا تشغيل لملفات الأدلة. [حالة المتطلبات والفجوات](docs/Implementation-Status.md).

## الذكاء الاصطناعي وورشة البرمجة

الموصل المحلي يدعم خادمًا متوافقًا مع واجهة OpenAI الخاصة بـ llama.cpp أو Ollama، دون مفتاح خارجي. الأوزان والمحرك غير مضمّنين. يجب تجهيز نموذج مجاني من مصدره الرسمي والتحقق من ترخيصه وسلامته قبل التشغيل. اضبط `WAS_AI_URL` على عنوان IP loopback، مثل `http://127.0.0.1:8081/v1`، و`WAS_AI_MODEL` على اسم النموذج الذي يدعمه خادمك. يرفض الموصل عنوانًا خارجيًا أو إعادة توجيه؛ لا ينزّل نموذجًا أو يبدأ خدمة تلقائيًا. اختيار الأدلة صريح، حتى أربعة أدلة و6000 بايت مقتطف من كل دليل. لا أدوات تنفيذ للمساعد ولا ضمان دقة.

ورشة Python تتطلب Bubblewrap وuser namespaces على Linux. تحد الذاكرة بـ192 MiB والمعالج بـ3 ثوانٍ والوقت بـ10 ثوانٍ، وتمنع شبكة المضيف وملفات المشاريع. عند فشل العزل ترفض التنفيذ. بيئة Codex الحالية تمنع إعداد uid map؛ تحقق مسار الرفض فقط. لا تتجاوز قيود المضيف لتفعيل الورشة.

## النسخ والاستعادة

من إدارة المنظومة نزّل نسخة مشفرة بكلمة حماية مستقلة؛ لا تحفظ المنصة الكلمة. يستخدم التشفير AES-256-GCM وScrypt بملح عشوائي. الحد الحالي للنسخ 120 MiB من الأدلة؛ ليست آلية نسخ ضخمة متدفقة. الأصل وقاعدة البيانات في مجلد البيانات غير مشفرين بواسطة التطبيق؛ استخدم تشفير قرص Linux للبيانات الحساسة.

الاستعادة إلى مجلد جديد فقط:

```bash
.venv/bin/python -m cyber_platform restore /path/backup.cyberbackup /path/new-data
bash scripts/start.sh --data /path/new-data
```

تطلب الطرفية كلمة الحماية دون إظهارها، وتتحقق من وسم التشفير والبيان والبصمات وسلامة SQLite وسلسلة التدقيق قبل نشر المجلد. لا تستعاد جلسات الدخول. احتفظ بنسخة خارج قرص الجهاز وبكلمة حمايتها في مكان منفصل؛ فقدان الكلمة يعني تعذر الاستعادة.

## المستودع والخصوصية

احفظ الكود في مستودع GitHub خاص **Private**. مجلدات البيانات والمفاتيح والنسخ و`.env` مستبعدة من Git. لا تغيّر خصوصية المستودع إلى عام، ولا ترفع الأدلة أو ملفات كلمات المرور أو أوزان النماذج. لا تضع صلاحيات أو رموز GitHub داخل الكود. النشر والرفع منفصلان عن تشغيل التطبيق محليًا.
