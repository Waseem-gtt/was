# حزمة0.7.0

هذه النسخة تزيل فريق الوكلاء من المنتج. المساعدون المستخدمون لتطوير المستودع يعملون خارجه. تبقى المحادثة المحلية الفردية اختيارية، دون نموذج مرفق أو تنفيذ أوامر من إجاباته.

أضيف فحص بصمات الأدلة على دفعات مع حفظ التقدم واستعادته. راجعREADMEوdocs/Integrity-Scans.mdداخل المصدر للحدود والتشغيل، و[تقرير0.7](../../docs/Validation-0.7.md) لنتائج الاختبار.

يثبتprovenance.jsonالتزام المصدر والبصمات. للتحقق شغّل `sha256sum -c SHA256SUMS` داخل هذا المجلد. البصمات ليست توقيع ناشر. الحزمة لا تشمل قاعدة بيانات المالك أو أدلته أو رموزه أو أوزان نماذجه.
