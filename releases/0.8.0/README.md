# حزمة 0.8.0

أضيف التحقق من الإصدارات الموقعة بـEd25519، وتثبيت الثقة ومنع خفض التسلسل في مسار الترقية الاختياري على Linux. راجع docs/Signed-Releases.md داخل المصدر و[تقرير التحقق](../../docs/Validation-0.8.md).

هذه حزمة تسليم غير موقعة بمفتاح ناشر حقيقي. اختبارات التوقيع استخدمت مفاتيح مؤقتة فقط، ولم تُنشأ مفاتيح مالك أو تُضبط الثقة نيابة عنه. البصمات تكشف التغيير وليست توقيع ناشر. لا تتضمن الحزمة بيانات تشغيل المالك أو أدلته أو رموزه أو مفاتيحه أو أوزان نماذج.

يثبت provenance.json التزام المصدر وحجم وبصمة الملفات. للتحقق شغّل `sha256sum -c SHA256SUMS` داخل هذا المجلد. تقرير التسليم يضيف نتيجة تجربة الإصدار الكاملة؛ أرشيف المصدر يطابق الالتزام المسجل قبل إضافة هذا التغليف.
