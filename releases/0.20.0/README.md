# حزمة 0.20.0

تضم المصدر والبرنامج وتقرير التحقق وبصمات الملفات. راجع فهرس المشروع وأدلة الوظائف داخل المصدر.

المصدر يطابق الالتزام المحدد مع استثناء مجلد releases كاملًا لمنع تداخل الحزم التاريخية وتضخم الأرشيف؛ تبقى الحزم السابقة في المستودع الخاص.

هذه حزمة غير موقعة بمفتاح ناشر؛ البصمات ليست توقيعًا. لا تتضمن بيانات تشغيل المالك أو مفاتيحه أو نماذجه. للتحقق شغّل `sha256sum -c SHA256SUMS` داخل المجلد.
