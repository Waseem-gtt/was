# حزمة 0.10.0

تضم الدفعة محولات Windows JSON وSyslog RFC5424 وتدفقات CSV، ومكتبة كشف من8قواعد مع مراجعات مالك واختبارات مرجعية، وخريطة تغطية دفاعية مرتبطة بأدلة. توسعت اختبارات الجودة إلى48حالة وأصلح ترتيب تحرير قفل التنفيذ قبل إرسال الاستجابة. راجع [تقرير التحقق](../../docs/Validation-0.10.md) وأدلة المحولات والكشف والتغطية داخل المصدر.

لا تعني التغطية الثابتة حماية حية؛ المحولات محددة الصيغة والقواعد مطابقة حقول، وبيانات الأمثلة اصطناعية. حزمة التسليم غير موقعة بمفتاح ناشر. البصمات تكشف التغيير وليست توقيعًا. لا تتضمن بيانات المالك أو أدلته أو رموزه أو مفاتيحه أو أوزان نماذج. يبقى فريق الوكلاء داخل المنتج ملغى، ومساعدو التطوير خارجه.

يثبت provenance.json التزام المصدر وبصمات الملفات. للتحقق شغّل `sha256sum -c SHA256SUMS` داخل هذا المجلد. ملفات المصدر تطابق الالتزام المسجل قبل إضافة هذا التغليف.
