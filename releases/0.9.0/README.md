# حزمة 0.9.0

أضيف مركز جودة الأدوات بحالات مرجعية اصطناعية وتقدم محفوظ ومقارنة تراجع وتحسن وتصدير التقارير. يختبر45حالة على21أداة؛ لا يمثل قياس فعالية جميع التخصصات. راجع docs/Quality-Center.md داخل المصدر و[تقرير التحقق](../../docs/Validation-0.9.md).

حزمة التسليم غير موقعة بمفتاح ناشر؛ البصمات تكشف التغيير وليست توقيعًا. لا تتضمن بيانات المالك أو أدلته أو رموزه أو مفاتيحه أو أوزان نماذج. يبقى فريق الوكلاء داخل المنتج ملغى، ومساعدو التطوير خارجه.

يثبت provenance.json التزام المصدر وبصمات الملفات. للتحقق شغّل `sha256sum -c SHA256SUMS` داخل هذا المجلد. ملفات المصدر تطابق الالتزام المسجل قبل إضافة هذا التغليف.
