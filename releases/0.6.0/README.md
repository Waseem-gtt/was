# إصدار0.6 مسحوب من التنزيل الحالي

ألغى المالك ميزة فريق الوكلاء داخل المنتج في0.7؛ الوكلاء المساعدون مخصصون لتطوير المشروع خارج التطبيق. لذلك أزيل أرشيف مصدر0.6وحزمةwheelوبصمات تنزيلها من الفرع الحالي، لاحتوائهما على الميزة الملغاة.

يبقى بيان المنشأ وتقرير التحقق هنا سجلًا تاريخيًا لملفات الإصدار الأصلي؛ بصماتهما تصف الحزمة القديمة، وليست قائمة تنزيل متاحة الآن. لم يُعدّل سجلGitأو تُحذف بيانات تشغيل المالك.

استخدم المصدر الحالي والإصدارات الأحدث، وراجع [تعديل النطاق](../../docs/Scope-Update-0.7.md).

هذا مجلد داخل تبويبCodeفي المستودع الخاص؛ ليس إعلانًا بإنشاء إصدار في تبويبGitHub Releases.
