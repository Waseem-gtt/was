# حزمة التسليم0.6.0

تحتوي الحزمة أرشيف المصدر وحزمةwheelوتقرير التحقق وبصماتSHA-256وبيان المنشأ. الالتزام المحدد فيprovenance.jsonهو مصدر الحزمة؛ تعديلات ملفات التسليم اللاحقة تظهر في سجلGitولا تغير مصدرها التاريخي.

للتحقق داخل هذا المجلد شغّل `sha256sum -c SHA256SUMS`. البصمات المحلية وSHAالتزامGitليست توقيع ناشر. المصدر يحتوي المتطلبات والتوثيق واختبارات هذه النسخة، دون بيانات تشغيل المالك أو رموزه أو نماذجه. النموذج المحلي الحقيقي ليس مرفقًا أو مختبرًا؛ فريق40دورًا يحتاج محركًا محليًا مضبوطًا، ويعمل بطلبين متزامنين كحد أقصى.

للتثبيت والتشغيل راجعREADMEفي أرشيف المصدر، ولحدود الإصلاح والترقية والوكلاء راجعdocs/Maintenance.mdوdocs/Agents.md. تقرير [التحقق](../../docs/Validation-0.6.md) و[ملخصه البرمجي](../../reports/validation-0.6.json) يميزان الاختبار الاصطناعي من الاستدلال الحقيقي.

هذا مجلد داخل تبويبCodeفي المستودع الخاص؛ ليس إعلانًا بإنشاء إصدار في تبويبGitHub Releases.
